## Configuration

| Key                                            | Description                              | Type      | Default      |
| ---------------------------------------------- | ---------------------------------------- | --------- | ------------ |
| `material-icon-theme.activeIconPack`           | Select an icon pack that enables specific icons.           | `string`  | `"angular"`  |
| `material-icon-theme.files.associations`       | Set custom file icon associations.       | `object`  | `{}`         |
| `material-icon-theme.folders.associations`     | Set custom folder icon associations.     | `object`  | `{}`         |
| `material-icon-theme.rootFolders.associations` | Set custom root folder icon associations. | `object`  | `{}`         |
| `material-icon-theme.languages.associations`   | Set custom language icon associations.   | `object`  | `{}`         |
| `material-icon-theme.files.customClones`       | Clone any existing icon and create a new one with custom colors and associations             | `array`   | `[]`         |
| `material-icon-theme.languages.customClones`   | Clone any existing icon and create a new one with custom colors and associations             | `array`   | `[]`         |
| `material-icon-theme.folders.customClones`     | Clone any existing icon and create a new one with custom colors and associations             | `array`   | `[]`         |
| `material-icon-theme.folders.theme`            | Set the type for the folder icons.            | `string`  | `"specific"` |
| `material-icon-theme.folders.color`            | Change the color of the folder icons.            | `string`  | `"#90a4ae"`  |
| `material-icon-theme.rootFolders.color`        | Change the color of the root folder icons.        | `string`  | `"#90a4ae"`  |
| `material-icon-theme.files.color`              | Change the color of the file icons.              | `string`  | `"#90a4ae"`  |
| `material-icon-theme.opacity`                  | Change the opacity of the icons.                  | `number`  | `1`          |
| `material-icon-theme.hidesExplorerArrows`      | Hide explorer arrows before folder.      | `boolean` | `false`      |
| `material-icon-theme.saturation`               | Change the saturation of the icons.               | `number`  | `1`          |
| `material-icon-theme.enableLogging`            | Enable logging to the output channel.            | `boolean` | `false`      |
| `material-icon-theme.logLevel`                 | Set the log level for output messages.                 | `string`  | `"info"`     |
